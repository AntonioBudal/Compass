# Compass

O Compass é um motor determinístico de execução pessoal que cruza intenções cadastradas com restrições de contexto em tempo real para responder continuamente qual é a próxima ação mais viável e relevante, eliminando a fadiga de decisão.

## Tecnologias (Stack)

*   **Backend:** C# / .NET 10 / ASP.NET Core Web API
*   **Frontend:** Vue 3 / Vite / TypeScript / Pinia
*   **Banco de Dados:** PostgreSQL 16
*   **Infraestrutura:** Podman
*   **Testes:** xUnit / Vitest

## Primeiros Passos

Este projeto utiliza **Podman** para gerenciar o banco de dados de desenvolvimento. Certifique-se de ter o Podman, .NET SDK (>= 8.0) e Node.js (>= 20) instalados.
